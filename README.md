# RestaurantPOS — Andhra Dining

[![HTML5](https://img.shields.io/badge/HTML5-E34F26?logo=html5&logoColor=white)](https://developer.mozilla.org/en-US/docs/Web/HTML)
[![CSS3](https://img.shields.io/badge/CSS3-1572B6?logo=css3&logoColor=white)](https://developer.mozilla.org/en-US/docs/Web/CSS)
[![JavaScript](https://img.shields.io/badge/JavaScript-F7DF1E?logo=javascript&logoColor=black)](https://developer.mozilla.org/en-US/docs/Web/JavaScript)

A beautifully designed restaurant website for **Andhra Dining**, showcasing authentic South Indian cuisine with an elegant UI featuring hero sliders, interactive menus, event galleries, and reservation functionality.

## Features

- **Hero Slider** — Full-screen image carousel highlighting signature dishes and ambiance
- **Interactive Menu** — Browse categorized dishes with pricing and descriptions
- **About Section** — Restaurant story, philosophy, and chef profiles
- **Event Gallery** — Showcase of special events, private dining, and celebrations
- **Reservation System** — Table booking interface for customers
- **Testimonials** — Customer reviews and ratings
- **Responsive Design** — Fully optimized for desktop, tablet, and mobile devices
- **Ayurveda Page** — Dedicated section on health-conscious Ayurvedic cuisine

## Tech Stack

| Technology | Purpose |
|-----------|---------|
| **HTML5** | Semantic page structure |
| **CSS3** | Custom styling, animations, and responsive layouts |
| **JavaScript** | Interactive elements, slider, and dynamic content |

## Getting Started

No build tools required — simply open `index.html` in your browser.

```bash
git clone https://github.com/gautammanak1/RestaurantPOS.git
cd RestaurantPOS
open index.html
```
